# MiniCart

MiniCart is a small Australian online retailer built as a production-focused software and DevOps learning project.

## Project roles

- Frontend Developer
- Backend Developer
- Cloud/DevOps Engineer

## Architecture

- React and Vite frontend
- Node.js and Express backend
- MySQL database
- Docker and Docker Compose
- GitHub Actions with AWS OIDC
- Amazon ECR
- Amazon ECS/Fargate

## Current stage

Day 3 establishes Git and GitHub and builds the first backend API.

## Initial endpoints

- `GET /`
- `GET /api/health`
- `GET /api/products`
- `GET /api/products/:id`
